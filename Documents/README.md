# Documentación del prototipo

- `functional-analysis.md`: alcance, flujo, actores, requisitos, supuestos y criterios de aceptación.
- `provisional-architecture.md`: arquitectura tentativa, componentes, modelo conceptual y decisiones diferidas.
- `process-reference.png`: diagrama utilizado como referencia del proceso actual.

La documentación distingue el proceso actual —que utiliza usuarios genéricos y tareas móviles— de la propuesta seleccionada: una aplicación web con identificación individual del operador.
