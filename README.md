# Entrega HH SUC — prototipo

Wireframe funcional de escritorio para validar la propuesta de una aplicación web de entrega en sucursal con usuarios nominales.

## Recorrido sugerido

1. Seleccionar **Usar una pieza de prueba**.
2. Iniciar la entrega.
3. Probar los caminos **Pieza entregada** y **Pieza no entregada**.
4. Completar todos los campos visibles.
5. Simular fotografía y, para una entrega exitosa, firma.
6. Revisar, confirmar y observar el resultado simulado.

## Ejecución local

```text
npm install
npm run dev
```

Abrir la dirección local informada por la aplicación. El prototipo está diseñado para un ancho mínimo de 1180 px.
